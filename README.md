# Medical Sales & Inventory Dashboard

Interactive Power BI dashboard created to analyze medical sales, cost, profit, quantity, and return trends.

## Features
- KPI Cards
- Department-wise analysis
- Specialization-wise analysis
- Drug-level insights
- Interactive slicers and filters

## Tools Used
- Power BI
- DAX
- Data Visualization
